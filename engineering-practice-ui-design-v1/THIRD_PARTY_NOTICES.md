# Third-party material in this design export

The export preserves the implemented UI and its local imports. It does not assign a new blanket license to the owner's design or screenshot.

- The vendored Shadcn/Tailwind stylesheet is accompanied by its original license at `reference-source/vendor/shadcn-tailwind-4.13.0.LICENSE.md`.
- License files from the installed packages imported by the included source are copied into `third-party-licenses/`. The package-to-file mapping is in `source-provenance.json`.
- The dependency inventory records the original imports and package versions. Preserve applicable package licenses and notices when installing or redistributing those dependencies in the target application.
- The reference image is an unchanged screenshot supplied by the owner. It is visual implementation context, not a stock image or a newly generated design.
- The favicon is copied unchanged from the original application's `public/favicon.svg`.

No fonts or third-party image libraries have been added to this export. The implemented font choices are system font stacks.

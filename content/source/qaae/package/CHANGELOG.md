# Changelog

## 1.1.0-draft — 2026-11-19

Package renamed from `QAAE-LESSON-01` to `QAAE-Q01`, because it now holds the whole module.

- Adds four lessons, each at `1.0.0-draft`: "Set up a safe workspace" (`LS-M001-01`), "When
  something goes wrong" (`LS-M001-02`), "Lesson 4: Run a test someone else wrote" (`LS-Q01-02`)
  and "Lesson 5: How good are your tests?" (`LS-Q01-03`).
- Adds three kits, each at `1.0.0-draft`: `M001-LAB-01` (`Workspace_Check_Kit_v1.zip`),
  `QAAE-LAB-Q01-02` (`QAAE_First_Run_Kit_v1.zip`) and `QAAE-LAB-Q01-03`
  (`QAAE_Sample_Grading_Kit_v1.zip`).
- Adds 21 activities, `ACT-M001-01-01` to `ACT-Q01-03-05`.
- Corrects Lesson 1 to `1.0.1-draft`. It promised that "the next lesson" would both set up the
  computer and run a test, which now takes three lessons. Three sentences changed: the `deferred`
  entry, the fourth paragraph of the introduction, and the last paragraph. Its three activities
  move to `1.0.1-draft` with it.

## 1.0.0-draft — 2026-11-03

- First release of the QA Automation Engineering course.
- Adds Lesson 1, "What changes when a machine runs your test?" (`LS-Q01-01` at `1.0.0-draft`), and
  its three activities, `ACT-Q01-01-01` to `ACT-Q01-01-03`.

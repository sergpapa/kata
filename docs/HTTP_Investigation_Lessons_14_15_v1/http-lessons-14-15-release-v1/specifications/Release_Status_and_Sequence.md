## Sequence clarification

The previous release described Lessons 14–15 loosely as an “investigation and transfer” batch. The original depth map is more precise: M021-06 is diagnosis and M021-07 is repair/regression, followed by M021-08 review and M021-09 later independent transfer. This release follows those stable meanings.

Lesson 15 includes a short supported transfer case with a different failure location. It is useful practice, not a claim that the separate later transfer assessment is complete. This clarification prevents a smaller guided exercise from silently replacing the planned independence evidence.

## What has become concrete

The new lab provides a fictional incident report, response contract, distracting style change, live source edits, a deliberately faulty validator, meaningful failing cases, a correct repair, a skipped learner regression worksheet and completed example, author CLI captures, and a second selection defect.

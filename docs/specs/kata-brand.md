# Kata brand in the app

**Status:** criteria agreed with the owner 2026-11-19. The logo set itself lives in `docs/brand/kata/`
(master `kata-logo.vectorcraft`, regenerated by `build_kata.py` with VectorCraft's CLI).

## What changes

The product is renamed Kata everywhere a person reads the product's name in the running app, and the
Kata brush mark replaces the old angle-bracket mark.

## Acceptance criteria

- [ ] **B1. Sidebar brand.** The sidebar shows the Kata brush mark and the KATA wordmark. The
      wordmark is an image whose accessible name is "Kata"; the mark beside it is decorative
      (`alt=""`), so a screen reader hears the name once. "Owner rehearsal" stays beneath the name.
      The sidebar no longer contains the text "EduCode".
- [ ] **B2. Breadcrumb.** The trail's first item reads "Kata". It still links to `/` everywhere but
      the course list, where it is plain text, exactly as "EduCode" did.
- [ ] **B3. Page head.** The browser tab title is "Kata". The page declares a 32 px and a 16 px
      PNG favicon, and every icon file it names exists in `apps/web/public/`.
- [ ] **B4. Not repeated.** The product name is not repeated in the page body (S6 of the visual
      design slice, carried over from "EduCode" to "Kata").
- [ ] **B5. Server console.** The server's start, failure and shutdown lines say Kata.
- [ ] **B6. Unchanged on purpose.** Export files keep the name `EduCode_<course>_Lessons_…md` and
      the heading `# EduCode export`, because ADR 0020 fixes that format and the owner may already
      have sent files under it. Internal names stay: `EDUCODE_*` environment variables, the
      `@educode/*` workspace packages, the `educode.*` storage keys and the SQLite file name.
- [ ] **B7. Every route, both schemes, three widths.** `npm run screenshots` passes, including the
      axe-core check (ADR 0021). The sidebar is navy in light and dark, so one light-on-navy asset
      serves both.

## Assumptions (not asked; defaults recorded)

- Favicons only: 32 px and 16 px PNGs. No web-app manifest or Apple touch icon, since the app runs
  in a desktop browser on the owner's machine.
- The app's assets are two transparent SVGs made from the same master as the logo files: the mark
  in `--sidebar-foreground` with a `--lime` centre, and the wordmark in `--sidebar-foreground`. No
  web font is loaded; the wordmark's letters are outlines.
- B5 has no automated test: the lines are `console.log` calls in the process entry point, which no
  test boots. It is checked by running the server.
- `README.md` is not changed in this slice: the owner has an uncommitted rewrite of it in progress.

## Out of scope

Renaming the repository, the packages, environment variables, storage keys or the export format;
any colour change to the app (the brand uses the existing tokens).
